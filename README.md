# مشروع بناء ونشر تطبيق ويب باستخدام DevOps وAWS

## وصف المشروع

يهدف المشروع إلى بناء بيئة متكاملة لتطوير وتشغيل ونشر تطبيق ويب
باستخدام تقنيات DevOps والحوسبة السحابية.

## أهداف المشروع

- تعلم إدارة Linux Servers.
- تشغيل تطبيق ويب.
- إعداد Nginx كـ Reverse Proxy.
- استخدام Docker لتشغيل الخدمات.
- أتمتة البناء والاختبار باستخدام GitHub Actions.
- إنشاء البنية التحتية باستخدام Terraform.
- نشر التطبيق على AWS.
- مراقبة التطبيق والخدمات.

## التقنيات

- Ubuntu Linux
- Java
- Maven
- MySQL
- Nginx
- Docker
- Git & GitHub
- Terraform
- AWS
- GitHub Actions

## مراحل التنفيذ

1. تجهيز بيئة Linux.
2. بناء التطبيق.
3. تشغيل التطبيق وقاعدة البيانات.
4. إعداد Nginx.
5. استخدام Docker.
6. إنشاء CI/CD.
7. إنشاء AWS Infrastructure.
8. النشر والمراقبة.
